# SaveMoney · 个人本地记账

免费、轻量、面向 iPhone 的本地记账 PWA；无需账号、登录或订阅。

**[打开 SaveMoney](https://jun-wu05.github.io/SaveMoney/)**

> **账本只存储在当前浏览器或主屏幕 Web App 的本地 IndexedDB。** SaveMoney 没有账单服务器、账号或自动云同步。手机遗失、卸载主屏幕应用、清除网站数据、存储故障，都可能让账本无法恢复。请定期导出完整 JSON，确认文件保存在 iCloud Drive 或其他独立位置。详见 [数据安全说明](docs/DATA_SAFETY.md)。

## 当前功能

- **快速记账**：支出与收入、金额、分类、日期、备注；记账数字键盘、常用分类排序、复制上一笔；支持编辑、复制、删除。保存成功后有反馈。
- **账单明细**：月度列表 / 消费日历双视图，日期、分类、类型和关键词筛选，查看每日收支；账单条目可独立左滑显示删除操作。
- **统计与回顾**：首页收支、消费结构与最近账单；每日支出、分类排行、六个月趋势、月度回顾与本地消费洞察。
- **预算管理**：月度总预算与支出分类预算。
- **分类管理**：新增、重命名、图标设置；已被账单引用的分类不可直接删除。
- **数据管理**：JSON 完整备份、备份文件只读校验、恢复预览和覆盖恢复；CSV 导入与导出、Excel（XLSX）月度分 Sheet 导出及账单导入，提供导入预览和去重处理。
- **离线与更新**：首次联网并缓存资源后可在支持的环境下离线打开；发现新版本后由用户确认更新。

> **只有 JSON 是完整备份格式**（账单、分类、月度预算、分类预算）。CSV / Excel 可导入或导出账单，但不等价于完整账本恢复，也不应替代 JSON 备份。

## iPhone 交互基线

底部四个主标签为**首页、账单、统计、设置**，通过**点击**切换。为提高 Safari 和主屏幕 PWA 的稳定性，**已经取消主标签左右滑动和设置子页滑动返回**；设置二级页面使用明确的「返回设置」按钮。账单条目的独立左滑删除不是页面导航，仍保留。

## iPhone 使用与备份

1. 在 Safari 打开 [在线应用](https://jun-wu05.github.io/SaveMoney/)，通过「分享 → 添加到主屏幕」安装。
2. 从实际打算长期记账的入口打开并新增账单；检查首页、账单、统计是否同步显示。
3. 进入 **设置 → 数据管理**，导出完整 JSON，确认在「文件」App / iCloud Drive 中确实可以找到文件。
4. 返回应用手动记录已确认保存，并用「校验 JSON 备份文件」只读检查格式。
5. 恢复前务必先导出当前账本，检查预览；恢复操作**覆盖**现有账单、分类及预算，不是合并。

Safari 标签页和主屏幕 Web App 可能使用独立存储容器，不要假定数据共享。建议至少每周保留一份设备外备份，最好保留不同日期的副本。**不要为解决更新或显示问题直接卸载应用或清除网站数据。**

## 开发与发布

技术栈：React 19、TypeScript、Vite、Dexie / IndexedDB、Vitest、Lucide；GitHub Actions 构建，GitHub Pages 托管。Node.js 22 与 npm。

```bash
npm install
npm run dev
npm test
npm run build
```

按 **Issue → 短期分支 → PR → CI 测试/构建 → 合并 main → Pages 发布 → iPhone 验收** 工作。CI 成功只证明相应自动检查通过，不能代替 Safari 与主屏幕 PWA 上的触摸、离线、下载和恢复验证。项目不含业务后端或付费 API。
