# iPhone PWA 输入框缩放防回归规范

## 原因
iOS Safari / 主屏幕 PWA 聚焦计算字体小于 16px 的可编辑表单时可能自动放大页面；关闭键盘后不一定恢复。

## 开发约束
- 所有可编辑的 input、textarea、select 计算字体不得低于 16px，包含预算、分类预算、搜索、好物、商品评价、备注和弹窗。
- 新增表单优先复用全局样式，避免局部 CSS 用更高优先级将字号覆盖为 12–15px。
- 保留 viewport 的用户缩放能力；不得使用 user-scalable=no、maximum-scale=1 等手段掩盖问题。
- 不更改 IndexedDB schema、账单与预算数据。
- 自动检查仅验证静态样式，iOS Safari 与安装到主屏幕的 PWA 仍需分别真机验收。

## 真机回归清单
1. 首页 → 月度预算 → 总预算输入：聚焦、键盘收起、保存、返回，页面不放大。
2. 月度预算 → 分类预算：输入、保存、取消后比例正常。
3. 设置 → 分类管理：新增与重命名输入正常。
4. 记一笔：金额、备注、新增分类、日期输入正常。
5. 账单：搜索、筛选正常。
6. 我的好物：搜索、名称、品牌、价格、要点、评价、分类、重复购买金额等输入正常。
7. 设置 → 首页显示：关闭彩票账本后首页不留空白；重启 PWA 仍隐藏；重新开启后入口恢复，原有账单不变。
8. Safari 浏览器与主屏幕 PWA 都测试，特别检查键盘关闭后缩放比例。

## 备注
显示彩票账本开关只控制首页入口，默认开启，设置存储于 localStorage；不删除彩票数据，不影响统计、预算或导出。
