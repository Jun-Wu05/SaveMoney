## 3. iPhone Safari 与主屏幕 PWA 专项验收

用户曾反馈一些功能在浏览器和 iPhone 上正常，但主屏幕 PWA 的页面滑动不稳定，已决定撤销。这不意味着以下所有场景均已全面完成实测。

- [ ] iPhone Safari：四个主标签仅点击切换，设置子页使用「返回设置」
- [ ] iPhone 主屏幕 PWA：四个主标签点击稳定、无全局页面左右滑动
- [ ] iPhone 主屏幕 PWA：设置按钮选中背景对齐、纵向滚动稳定
- [ ] 账单条目左滑删除不影响全局导航
- [ ] 记账弹层键盘、日期输入、固定保存按钮在不同 iPhone 屏幕尺寸正常
- [ ] 飞行模式：首次成功缓存后可离线打开、记账、重新启动
- [ ] 真实 JSON 文件导出后可在「文件」App / iCloud Drive 中找到、只读校验通过
- [ ] 在独立测试账本中恢复 JSON 并核对交易、分类与两类预算（禁止用唯一真实账本做覆盖演练）
- [ ] CSV / Excel 真机导入导出、异常行与去重处理
- [ ] Safari 与主屏幕 PWA 的数据隔离和各自备份入口已实际确认
- [ ] 新版本更新、后台恢复后原有本地账本未丢失

每项勾选应记录设备型号、iOS 版本、运行入口、步骤和验证结果；不能仅凭 GitHub CI 通过打勾。

## 4. 发布与安全要求

1. 按 Issue → 分支 → PR → 测试/构建 → 合并 main → Pages 部署 → iPhone 验收执行。
2. 更新或 UI 故障不得随意要求卸载应用、清理 Safari 数据。
3. 导入、恢复、迁移必须重视校验、确认、兼容与数据保全。
4. 在真实离线、备份保存和恢复测试尚不充分时，不宣称账本绝对不会丢失。
