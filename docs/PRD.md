# SaveMoney 当前产品需求与功能范围

> 基线：2026-10-23 GitHub `main`；此文档代替早期 MVP 的过时功能说明。代码实现与真机通过验收是不同状态。

## 产品定位

SaveMoney 是免费、轻量、隐私优先的 iPhone 个人记账 PWA。无需注册、登录或业务服务器。账本存在当前浏览器或主屏幕 PWA 本地 IndexedDB；用户自行备份，不自动云同步或共享。

## 页面与功能

| 页面 | 当前功能 |
| --- | --- |
| 首页 | 月度支出、收入、结余、消费结构、月度预算入口、最近账单 |
| 记账弹层 | 新增/编辑收支、数字键盘、分类、日期、备注、常用分类、复制上一笔、保存反馈 |
| 账单 | 月度列表与日历、每日收支、筛选与搜索、修改/复制/删除、条目独立左滑删除 |
| 统计 | 分类消费、每日支出、近六个月趋势、月度回顾与本地消费洞察 |
| 设置 | 分类与图标管理、账单显示偏好、帮助、隐私及数据管理 |
| 预算 | 月度总预算与支出分类预算 |
| 数据管理 | JSON 备份校验与恢复、CSV/Excel 账单导入导出与预览去重 |

### 导航与交互决策

底部四标签 **首页 / 账单 / 统计 / 设置** 通过**点击**切换。设置二级页面使用可见的「返回设置」按钮。**主标签横向滑动以及设置二级页滑动返回已经撤销，不属于当前需求。** 账单条目的左滑删除属于局部操作，继续保留。

## 数据和业务规则

- 金额合法性校验：有效正数、最多两位小数，存储用整数分。
- 账单日期按本地 `YYYY-MM-DD` 保存；跨月、跨年与闰年统计正确。
- 新增、修改或删除账单后，相关月度汇总、预算与图表反映更新后的本地数据。
- 分类可新增、重命名并修改图标；已有账单引用的分类受删除保护。
- 分类预算与总预算不改变原始交易记录；消费分析在本地计算。

## 文件与备份

| 类型 | 功能 | 限制 |
| --- | --- | --- |
| JSON（`savemoney-backup` v1） | 账单、分类、总预算、分类预算完整备份；文件只读校验；确认后覆盖恢复 | 恢复覆盖当前账本，不合并；用户要确认文件已安全保存 |
| CSV | 账单及汇总导出；兼容账单导入、预览和去重 | 不是完整备份 |
| Excel XLSX | 按月分 Sheet、汇总导出；兼容账单导入、预览和去重 | 不是完整备份 |
| 离线缓存 | 首次联网后可离线使用已缓存的应用资源 | 缓存不是账本备份 |

导入应在用户确认后执行，不因文件错误而静默覆盖账本。JSON 恢复须先验证格式并展示预览。备份文件的“生成”“人工确认已保存”“只读校验”是不同步骤。

## 验收标准

1. `npm test`、`npm run build` 通过；合并后 Pages build/deploy 成功。
2. Safari 与主屏幕 PWA 各自验证点击导航、键盘、弹层滚动、账单交互。
3. 完成数据导入导出、离线、备份文件保存及隔离测试账本恢复验证。
4. 不能仅凭自动测试通过宣称真实 iPhone 场景已完整验收。详细状态见 [checklist.md](checklist.md)。

## 当前非目标

账号/自动云同步、多用户共享、银行及支付平台自动接入、OCR、广告或付费 AI API。扩展范围需另行确认。
