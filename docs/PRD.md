# SaveMoney MVP 产品需求

## 定位
私人使用并分享朋友的极简记账 Web App。用户数据各自独立保存在本机，不需要登录。

## 页面
- 首页：本月支出、收入、结余、最近明细。
- 记一笔：收入/支出、金额、分类、本地日期、备注。
- 账单：按月展示，编辑、删除。
- 统计：本月支出分类排行。
- 设置：数据安全提示、JSON 备份恢复及 CSV 导出（下一阶段）。

## 核心验收
- 交易金额使用整数分，禁止零、负数、非法输入。
- 日期按本地日历存储，跨月统计正确。
- 新建、编辑和删除后汇总立即更新。
- 刷新页面时 IndexedDB 记录不丢失。
- 分享给朋友之前必须完成备份、恢复、PWA 离线测试。

## 非目标
银行同步、OCR、AI 分类、多人共享账本、注册登录、广告和商业付费。
